## 当前私有存储与系统相册方案

以下验证替代此前 SAF 目录方案；下方旧记录仅保留历史验收证据。

- 覆盖安装后直接进入应用，没有目录设置引导。旧授权目录及数据未修改；旧安装列表不再读取。
- 通过原生队列重新安装 TestGame，资源进入应用私有目录，实际启动成功。
- 点击游戏截图按钮后，MediaStore 显示 `relative_path=Pictures/VIPRPG.org/`、`is_pending=0`，本应用图库直接显示新截图，没有存储／相册授权弹窗。

未覆盖所有 Android 版本和文件提供方；系统相册卸载保留规则依据 Android MediaStore 契约，本次未卸载用户应用进行破坏性验收。

## 历史 SAF 方案实际验证

- 首次选择本地目录，建立 `games`、`screenshots`、`saves`；图库不再另行索取目录。
- 从预生产只读接口安装三个游戏：69 文件 / 1,846,138 字节、135 文件 / 27,942,084 字节、3,192 文件 / 438,410,982 字节。校验完成后才显示可游玩。
- 大文件下载期间切到桌面，临时文件继续增长；强制停止后重新打开 App，任务恢复并安装完成。此项证明中断恢复，不代表该次请求已证明 HTTP 206 续传。
- 下载到约 192 MB 后点击取消并确认，任务消失，私有临时包与未完成安装被清理。
- TestGame 实际启动、输入、保存 File1；重启后读取 `Save01.lsd`。删除并重新安装游戏仍能读档，截图保留。
- 同作品的第二版本使用本地验收夹具，读取同一作品存档。证明按作品共享存储，不代表任意游戏内容版本天然兼容。
- 实际游戏截图写入共享根目录下的 `screenshots` 并由原生图库显示。
- 音频 Worker 读取原生资源后渲染出非零 PCM；未做听感评价。
- 合成 MP4 通过原生区间流播放；AVI 经 FFmpeg Worker 从同一目录解码，输出 20 帧视频与 87 块音频。不是全部编码格式回归。
- 将授权目录改名后，App 回到目录引导；重新选择改名后的目录，恢复游戏清单及存档访问。未模拟操作系统单独撤销授权的全部情形。

### ZIP 存档回导与选择性覆盖

仅接受根目录直接包含 SaveNN.lsd 的 ZIP，不支持子目录或其他文件。MuMu 选择此前实际导出的双存档 ZIP，确认冲突项默认未选且导入按钮禁用；只勾选 Save01 后导入成功，保存内容与 ZIP 一致，Save02 和其他已有文件保持不变。单个 LSD 与 ZIP 共用冲突多选器，未勾选项保留，新槽位一并导入。最终 APK 构建、Android lint 和差异空白检查通过。
