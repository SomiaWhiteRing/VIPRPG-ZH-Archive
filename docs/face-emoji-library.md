# 角色脸图表情库

表情来自已审核角色脸图的 48×48 格子。图片哈希和行列唯一确定一个不可变表情引用，角色绑定仅用于搜索与来源展示。多人共用脸图不推断格子人物；取消收藏、角色改名、合并或解绑不改变已发布内容。素材审核撤销、图片不可用或尺寸不匹配时显示不可用占位。

## 用户入口

头像菜单与个人中心的「表情库」进入 `/me/emojis`，页面复用脸图工作台的左右分栏与选格画布。左侧是人物树下拉框和脸图表，右侧固定显示「我的表情」，不再使用三个标签页。下拉框的首个选项为「全站热门」，角色按现有分类树展开，角色项左侧显示统一高度的默认脸图；中文名、日文名和别名搜索走服务端分页，分类展开时才加载成员。桌面端脸图表固定三列；窄屏按左栏、右栏依次排列，脸图表保持每行两张素材。工具界面仅保留名称、操作与状态反馈，不显示操作说明和排序说明。

默认点击左侧格子或右侧表情进行单项预览，预览右侧提供「加入我的表情」或「从表情库移除」。两栏标题区各有默认关闭的多选图标按钮，关闭时显示边框，开启时显示主题色；两栏模式互斥，开启一栏会关闭另一栏并清空选择。按住 Ctrl 点击表情可自动开启该栏多选，并保留同栏已有选择；开启后可在对应栏逐项选择或取消选择，每次最多 256 个表情。预览显示选择数量，左栏可批量加入并自动跳过已收藏项，右栏可批量移除。右栏多选只改变右栏选择和预览，不切换或定位左栏，也不改变左栏当前格子高亮。关闭多选、切换角色或热门来源、点击另一栏时清空当前多选，切换来源和点击另一栏保留多选模式。移动端仅在选中表情时显示预览，并固定在视口底部；页面为预览保留空间。桌面端右侧表情悬停时显示小型主题色移除按钮，支持从左向右拖拽加入、从右向左拖拽移除，以及个人库内部单项和批量拖动排序。拖动选中项时，以实际拖起的格子为中心收拢选择，库内只保留一格，其他表情平滑让位；左栏拖入也预留一格，新收藏仍按原规则置前。松手后，堆叠从手中落到各项的实际位置，目标在其他分组或滚动区域外时落向对应标题或可见边缘。等待保存时保持堆叠，失败后恢复原顺序并回到原位置；快速起落或取消拖动会清理拖动状态。避让和落位期间禁用格子的指针交互，阻止松手后的误点击。取消拖拽或松手到其他区域不改变收藏与顺序。

左侧脸图使用角色详情素材表的固定顺序：角色绑定排序、素材来源排序、素材 ID，未设置排序的项目排在已设置项之后。右栏多选关闭时，点击右侧已有表情会让左侧自动切到关联角色，加载对应脸图所在分页并滚动定位、高亮具体格子，不将素材移到最前；可继续加载前后分页。共用脸图优先沿用当前角色，否则取来源列表首项，预览旁显示相关角色供切换，不推断格子人物。没有角色绑定的可用表情直接显示原脸图，不可用表情提示当前状态。角色素材的看图工具栏提供「收藏为表情」入口，正文表情可预览与收藏同款。

个人库首次打开时显式初始化默认清单，初始化标记独立于收藏记录。移除全部表情不触发再次初始化。收藏与手动排序随账号保存，编辑器沿用同一顺序；成功新发表后，只移动正文中已收藏的表情，按首次出现顺序置前。新增收藏按选择顺序置前，重复收藏不重排。手动排序只移动指定表情，批量拖动按库内当前顺序组成一个块，块内及其他表情的相对顺序保留；后续新增或使用仍按原规则置前。预览、草稿、失败提交、论坛幂等重试和编辑旧正文不触发最近使用更新。选择面板在下次打开时刷新，操作期间保持位置。

热门榜按近 30 天公开正文中使用过该格子的不同用户数排序，同分按最近有效发表时间、表情 ID 排序。正文编辑同步当前引用，时间窗口仍使用原发表时间；可见性跟随既有评论和论坛公开规则。隐藏、删除或父内容不可公开访问的记录不计入。没有热门数据时单独展示默认推荐。

## 默认清单

`/admin/emojis` 使用同一工作台管理默认清单，右侧显示默认清单；可拖动排序，或选中后前移、后移，统一点击保存。权限为 `emoji.defaults.manage`，沿用原表情管理角色范围；保存写入审计。默认清单变更不覆盖个人库。首批默认内容由管理员选定；未配置时清单为空，用户仍可自行收藏。

本站不再提供独立表情图片上传、人工短代码和退休模型。默认清单只引用脸图库内容。

## 个人分组

个人库使用顶部页签，初始仅有「全部」，不生成未分类分组。「全部」汇总全部收藏，每个收藏可以同时加入多个自建组，在全部中仍只显示一次。页签右侧加号直接创建当前账号下首个空缺的「表情组1」「表情组2」等名称，并选中新组。分组管理弹窗仅列出自建组，可修改名称、删除分组和使用 dnd-kit 手柄拖动排序，全部页签始终在库的首位。名称未修改时确认图标的位置留白，有实际修改时才显示图标；未修改时按 Enter 不提交。分组名称为 1 至 20 个字符，同一账号不得重名或使用「全部」。删除分组保留收藏及其他组的归属。右侧选中后的按钮始终为「从表情库移除」「编辑分组」，不随页签改变；「从表情库移除」按钮会取消收藏及全部归属。自建组内的悬停叉号仅移出当前组，保留收藏及其他组归属；全部页签的悬停叉号仍取消收藏及全部归属。拖入左栏时，自建组内的表情仅移出拖动起始组，全部页签的表情取消收藏及全部归属。

编辑分组弹窗左侧显示组名，右侧显示复选框，只有自建组参与编辑。所有选中表情都在组内时默认勾选，都不在时未选，部分在时半选；单选不出现半选。半选首次点击变为未选，之后按普通勾选切换。确认时把所有选中表情加入勾选组、移出未选组，仍为半选的组保持各表情原有归属。没有实际变化时禁用确认，改回原状也会禁用；取消、关闭、点击遮罩或 Escape 只丢弃本地草稿，不提交请求或改变归属。确认用同一批次保存，失败保留草稿；保存后保持当前页签与仍在该页签中的选择。

管理页支持单选和多选通过编辑分组加入其他组，保留原归属。从自建组拖到其他自建组时，在同一批次移出拖动起始组并加入目标组，保留收藏及其他组归属；即使目标组已包含该表情，也会移出起始组。拖到全部页签仅移出起始组，保留收藏；从全部页签拖到自建组只增加目标归属。拖到分组页签停留 300ms 切换视图，松手才修改归属，取消拖动或松手到无效区域不修改归属。左栏已收藏的可用表情仍可拖动；松手后先按本地库与目标组比较，仅提交新增收藏或缺少的归属，没有实际变化时不发送写入请求。表情拖到可加入或移入且尚未选中的分组标题上时显示高亮边框，移开、松手或取消后恢复。表情大区域沿用原有样式。点击「加入我的表情」直接加入当前选中组，正文表情浮窗也沿用本地记住的当前组，不再弹窗选择。新收藏按原规则置前，既有收藏增加归属或重复加入不改变排序和最近使用记录。组内复用个人库的既有排序和最近使用规则，分组自身顺序独立保存。

编辑器选择面板将分组合并到既有标题栏：「我的表情」代表全部收藏，自定义组紧接其后，不单独增加分组行。页签超出可用宽度时横向滚动，左右边缘按溢出方向显示渐隐背景与滚动箭头；恢复选中组和改变面板宽度时将当前页签带入可见区域。创建分组仅在表情库管理界面提供，选择面板原有加号继续打开表情库。所选页签按账号保存到本地，下一次打开选择器恢复；已删除或其他账号的分组回退到全部。切组分别保留滚动位置，不改草稿或光标。后台默认清单继续使用原工作台，不增加个人分组。

## 编辑与接口

评论与论坛共用 `BodyEditor`。表情为不可拆分的行内节点，输入和已发布正文中默认显示 24×24 图片，支持删除、撤销、复制和重新编辑。输入区中的表情只显示图片，点击不打开浮窗；已发布正文中的表情在桌面鼠标悬停或手机点击时打开预览浮窗，上方显示相关角色名，中间按整数倍放大为 96×96，下方提供「加入表情库」按钮。鼠标可移入浮窗操作，离开后延迟关闭；点击外部或按 Escape 关闭，悬停预览不抢占输入焦点。表情库和选择面板仍以 48×48 展示单格。论坛主题和普通回复继续支持正文插图；其他评论使用文字与表情模式。

快捷表情选择器不使用整屏弹窗。桌面端贴着表情按钮弹出可滚动网格，空间不足时自动避让，选中后插入原光标位置并保持面板打开，支持连续插入。手机端网格接在输入区工具栏下方，表情面板的操作栏放在顶部并保留左侧间距，系统键盘收起，支持连续插入而不重新聚焦输入框；表情按钮切换为键盘图标，点击可收起面板并继续输入。点击外部或按 Escape 也可关闭。面板复用个人库顺序，提供加载、空态和重试反馈；加号按钮单独打开管理工作台，关闭管理后返回选择器，保留草稿和原选区。

正文以 `:face_<引用 ID>:` 序列化表情；它是存储及剪贴板格式，不作为普通页面标签。复制编辑器或已发布正文时，富文本保留表情引用，纯文本使用这一稳定标记；站内粘贴可恢复图片节点。正文摘要、提醒和搜索内容转换为 `[表情]`。表情按一个 Unicode 字符计入正文长度，插图偏移继续使用序列化字符串的 UTF-16 偏移，不能落在表情标记中间。正文只解析并加载实际引用的表情。

`/api/emojis` 的 GET 提供 `resolve`、`library`、`defaults`、`hot`、`categories`、`characters`、`sheets` 查询；公开正文引用解析允许匿名，其余查询要求登录。`characters` 可按 `categoryId` 分页加载分类成员，同时返回可公开访问的默认脸图；`sheets` 可用 `focus` 图片哈希定位素材自然顺序中的分页，响应包含该页 `offset`，前后翻页只传 `offset`，不传 `focus`。POST 提供 `initialize`、`add`、`remove`。新增格子提交图片哈希和行列；接口批量添加或移除一次最多 256 项，工作台支持逐项操作和多选添加、移除。`/api/admin/emojis` 的 GET/POST 读取和保存有序默认格子清单。所有写入要求同源，个人库只操作当前账号。

POST `reorder` 接收待移动的 `ids`（最多 256 项）和插入位置后的 `beforeId`（`null` 表示末尾），原单项 `id` 请求继续有效。在同一 D1 batch 中根据当前账号的即时收藏顺序将所选表情作为一个块移动，保留块内与其他表情的相对顺序。仅更新已有收藏的排序字段，不添加或移除收藏、不生成热门使用记录；所有移动项和位置锚点均须属于当前账号，失效返回冲突，排序序号和收藏都不部分写入。并发设备的新增和移除保留。

个人库查询和写入响应同时包含 `userId`、`groups`、`emojis`，收藏项额外返回 `groupIds` 数组，每个收藏仅返回一次。POST `add` 接收目标 `groupId`（`null` 表示全部），既可新增收藏，也可给已有收藏增加目标归属；已有自建组时省略目标将被拒绝。POST `group.add` 批量增加已有收藏的指定归属，不生成最近使用记录。POST `groups.update` 接收所选收藏 `ids`、勾选的 `includeGroupIds` 和未选的 `excludeGroupIds`，两组目标须互斥，半选组不传入；同一 D1 batch 核实所有收藏及目标组属于当前账号，再整体增加和移出归属，失效时不部分写入，也不改变排序或最近使用记录。自建组之间的拖动复用 `groups.update`，目标组加入 `includeGroupIds`、起始组加入 `excludeGroupIds`；拖到全部时 `includeGroupIds` 为空。POST `remove` 携带自建组 `groupId` 时仅移出该组，省略或为 `null` 时删除收藏及全部归属；自建组的悬停叉号和拖入左栏操作携带起始 `groupId`。`group.create` 自动命名并返回 `createdGroupId`，`group.rename`、`group.delete` 和 `group.reorder` 管理当前账号的分组；排序同样接收移动项 `id` 和 `beforeId`，不覆盖其他设备新增的组。

`face_emoji_refs` 保存不可变格子，`user_emoji_library_state` 保存初始化与排序序号，`user_face_emojis` 保存个人库，`default_face_emojis` 保存默认清单。`0021_face_emoji_groups.sql` 增加 `user_emoji_groups` 和 `user_emoji_group_items`，归属关系以账号、收藏、分组三列为主键。复合外键保证收藏和分组属于同一账号，分组删除仅级联清除该组归属。加入和移出在同一 D1 batch 中核实即时目标，失效时不部分写入。评论、论坛楼层、楼中楼分别用引用表关联原正文并遵守外键。正文、引用和最近使用更新在同一 D1 batch 中执行；论坛引用同步受已有写入版本门控。新引用在服务层与数据库触发器中核实可用性，原有下架引用可随旧正文保留。

## 开发与验证

统一初始化 SQL 和固定开发快照使用这一模型。快照原有开发短代码已替换为实际脸图引用或不可用文字，保留其他业务数据和单条初始化迁移账本；默认清单留空，由后台配置。表情引用纳入 blob 清理保护。

现有数据库不会随同名初始化 SQL 自动升级；备份、重建与部署需要单独授权。检查遵循维护与回归手册：相关类型与 lint、现有论坛契约、种子完整性及路由构建；不默认新增测试代码或进行浏览器验收。

表情库与角色管理器共用 `app/components/ui/multi-drag.tsx` 的堆叠、单格占位、避让、落位和拖动状态清理。该层缓存索引，以线性扫描寻找最近目标，限制堆叠预览数量并缓存每个滚动区域的边界；表情库另缓存收藏映射、选中集合、分组计数与格子内容，避免指针移动时反复遍历和重绘所有头像。
