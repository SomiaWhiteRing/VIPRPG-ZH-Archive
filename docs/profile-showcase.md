# 个人喜爱展柜

`/me/showcase` 是个人中心的「喜爱展柜」菜单。活跃账户可从公开作品、角色和作者中各选择一项，并为每项填写最多 500 个 UTF-16 代码单元的纯文本附言。不要求先收藏作品，不提供创建资料实体的入口。

## 编辑与展示

- 保存后进入 `/users/:userId`，开启展示时在「最近游玩」等内容之前展示展柜。未选择的项目不显示，全部移除后整个展柜隐藏。
- 每项右侧放置复选框和排序控件，勾选后才显示选择器及附言表单。取消勾选暂时保留输入，提交时排除未勾选或未选择对象的项目。
- 桌面通过右侧把手拖动，复用表情库的 `ReorderItem` 位移动画，松手确定顺序，取消拖动恢复原顺序。把手也支持方向键及 Home／End。触屏使用上下移动按钮。
- 角色复用表情库的分类树及分页搜索界面，展柜查询包含无脸图角色；表情库仍只提供有可用脸图的角色。作品和作者按名称、别名搜索，候选显示封面或头像。界面不显示实体编号。
- 选择角色后可从该角色已绑定的公开脸图中选格作为展柜头像，也可恢复沿用默认头像。选择仅在保存展柜时生效，不修改角色的默认头像；更换角色时重置头像选择。
- `/me/privacy` 提供独立的「在个人主页展示喜爱展柜」设置，默认开启。关闭时公开主页不读取或返回展柜条目，本人仍可在个人中心编辑已保存的内容；开启但没有有效条目时整个展柜隐藏。
- 默认展开排序后第一个有附言的有效项目。无附言（含仅空白）的项目不能展开；所有项目均无附言时等宽排列，三项各占三分之一。桌面展开项加宽并在图片右侧展示附言，其他项保留名称和图片。窄于 620px 的内容区改为纵向排列。
- 只有一项可展开时直接展示其附言，不显示展开箭头或高亮。高度与各区域字号沿用 demo：桌面图片区高 157px，项目名称 17px，附言 14px；类型行 11px、主题色加粗，无装饰图标和悬停底色。展柜标题与个人主页其他栏目标题样式一致；附言沿用 demo 的 Segoe UI／Microsoft YaHei 字体和 1.9 倍行高。卡片内边距为 16px，窄屏 13px；图片与附言间隔为 18px，窄屏 13px，移动端附言及段落上内边距分别为 15px 和 12px。超长附言可滚动阅读。
- 鼠标移动到项目时切换，离开后保留当前项目。触屏可点击类型按钮或卡片空白处切换；标题和图片始终直接进入真实详情页。
- 类型按钮支持 Enter／空格，方向键与 Home／End 切换。附言保留换行并安全地作为文本渲染，未展开的附言对辅助技术隐藏。系统减少动态效果时关闭切换动画。
- 作品封面、角色默认脸图及作者头像沿用现有公共图片来源和占位组件；不上传或复制展柜专属图片。
- 表单保存成功使用全局 toast，失败在表单内显示并保留输入。离开未保存表单会提示；冲突提供显式重新读取，丢弃输入前再次确认。

## 数据与公开边界

统一初始化 SQL 定义 `users.showcase_revision`、默认值为 1 的 `users.profile_show_showcase` 和 `user_showcase_entries`。条目以 `(user_id, kind)` 唯一，顺序为 0–2，三个真实外键中恰有一个与类型对应。最多三个条目；没有选择的类型不写入数据库。

角色专属的 `portrait_ref_id` 引用现有 `character_portrait_refs`。写入前及事务内校验角色归属、脸图公开性与格子范围；角色合并时迁移到对应头像引用。绑定删除后头像引用置空，素材失去公开性时读取回退为默认头像。

读取时重新核对当前可见性：作品使用 `public_works`，作者至少署名于一部公开作品，角色身份沿用公开角色资料规则，脸图另按素材公开规则过滤。失效对象不进入公开主页的页面数据。本人编辑状态保留失效项目的引用及附言，界面只提示原选项不可用，允许替换或移除，不泄露已隐藏对象的标题或图片。

作品、角色和作者合并时，展柜外键随现有合并事务迁移，保留顺序及附言。目标被硬删除时级联删除条目；内容暂时不可公开时保留设置并暂停展示。停用账户的展柜不公开，注销账户时清除条目。

## 接口

`/api/account/showcase` 全部要求活跃会话和同源请求，用户身份仅取自会话；响应不缓存。

| 请求                                                 | 行为                                                                                                                              |
| ---------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| `GET`／`HEAD`                                        | 返回本人展柜及 revision                                                                                                           |
| `GET ?kind=work\|character\|creator&q=...`           | 最多 12 条公开候选，查询最多 100 个代码单元                                                                                       |
| `GET ?op=categories`                                 | 返回有角色的分类及祖先分类                                                                                                        |
| `GET ?op=characters&categoryId=...&q=...&offset=...` | 返回 24 条角色及是否有下一页；空分类标识表示未分类，省略则跨分类搜索                                                              |
| `GET ?op=portraits&characterId=...&offset=...`       | 返回 12 张角色公开脸图、是否有下一页与默认头像                                                                                    |
| `PUT`                                                | 接收 `{revision, entries:[{kind,targetId,note,portrait}]}`，按数组顺序整体替换；`portrait` 为 `null` 或 `{blobSha256,row,column}` |

保存批次先以 revision 和账户活跃状态守卫，再清除旧条目、写入新条目并记录 `showcase_updated` 审计。写入事务内再次核对目标可见性，失效或版本冲突会使整个批次回滚，不能把条件更新影响零行当成保存成功。

固定开发种子包含空展柜表、revision 初值和默认开启的展柜隐私设置，不替示例账户填入未经选择的内容。现有数据库需同步新增列及表；不能仅部署代码而忽略 schema。既有数据库的重建按根目录 `AGENTS.md` 单独授权。
