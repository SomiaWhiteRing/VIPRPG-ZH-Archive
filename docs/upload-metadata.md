# 上传资料、发布声明与制作署名

适用于 `/upload`、`/me/uploads/[workId]`、归档资料草稿及外链作品提交。数据归属见[游戏领域架构](./game-domain-architecture.md)。

## 文件预填与日期粘贴

- 发布日期为选填，表示作品最初发表的日期。留空时保存为 `originalReleaseDate: null`、`originalReleasePrecision: "unknown"`；归档上传、外链发布和作品编辑使用同一规则，填写后仍校验日期格式与精度，不自动补本站发布时间。已选择的日期可以清除。
- 从游戏 `RPG_RT.ini` 预读到的标题，在所选语言为简体或繁体中文且标题不含日语假名时填入中文名，否则填入原名；保留用户已经填写的内容。
- 新建角色和已有角色使用独立的脸图选择界面，沿用相同的弹窗标题和通用按钮文案。新建角色填写名称后，左侧自动显示当前上传作品 `FaceSet` 中有效的 PNG 整张脸图，可按文件名查找、选中后添加或拖入右侧；右侧保存整张素材表，可添加多张、移除，并点击其中一格指定本作头像。已有角色继续从自己的素材表选择头像。
- 作品脸图在资源清理前提取，支持文件夹、ZIP 和 7z 上传，按内容去重；尺寸、大小沿用角色脸图校验。BMP、XYZ 或无效文件显示未读取的原因，可转换为有效 PNG 后手动添加。候选和已确认的角色脸图保存在本地上传草稿中；取消或更换上传源时清空候选，保留已经确认的角色选择。
- 日期栏保留分段日历选择，也可粘贴日期。常规数字日期、紧凑数字日期和年份／年月直接识别；其他格式按需加载 [Chrono](https://github.com/wanasit/chrono#usage) 的中文、日文和英文解析器，支持中文数字、英文月份、日文年号、相对日期及带时间的日期文本，也接受 10 位秒／13 位毫秒时间戳。
- 保留明确的日期精度；缺少年份的普通日期不自动补当前年。多个日期、日期区间或美式／英式数字顺序存在歧义时显示候选，选择后写入。非法日期不覆盖原值。

## 发布声明

- 原创声明与翻译声明互斥，允许均未选择；仍使用两个复选框。
- 翻译声明选中时，在作者旁显示译者；切换声明不清空页面内译者草稿，也不抢焦点。
- 非翻译作品提交时不包含译者；取消翻译声明并保存会删除该作品的译者关联。
- 翻译作品必须至少填写一位译者。提交、锁定期间沿用工作台统一禁用状态。

## 制作人员边界

作者及其他制作人员只收录直接参与本作创作的人或团队。作者使用多人列表，编辑和草稿恢复保留全部作者，外链与归档提交使用同一署名集合。默认额外职务为策划、程序、剧本、美术、音乐、其他；选其他时填写实际职务名称。仅提供通用音乐、图像等素材而未参与本作制作的人，不作为本作制作人员自动收录。

额外制作人员位于“更多设置”内，保留标题，使用紧凑的职务、人物、移除行。选择“其他”时，在职务和人物之间插入占位提示为“职务名称”的输入框，与职务选择器等宽，保持同一行。全空行忽略，半填行和重复署名提示错误。折叠不删除记录，保存时以完整列表替换。

## 更多信息

- “更多设置”在其他制作人员之后提供“更多信息”，每条以标题、内容、移除左右排列，输入框内分别显示“标题”和“内容”占位提示。内容使用可调整高度的纯文本框，初始为一行。条目可添加和移除，按列表顺序保存和展示。
- 最多 20 条，标题最多 100 个 UTF-16 代码单元，内容最多 10,000 个；前后空白去除，内容内部换行保留。全空条目忽略，半填条目提示补全。相同标题允许重复。
- 折叠不清空内容；折叠摘要显示已填写数量，验证错误自动展开。提交、锁定期间沿用作品资料统一禁用状态。
- 归档提交使用 `ArchiveCommitMetadata.game.extra.moreInfo`；外链发布、作品修改与后台维护使用 `more_info` JSON 数组。服务端使用同一结构校验，保存完整列表，移除全部条目时显式提交 `[]`。本地表单草稿保存编辑原值，包括未填完整的条目。
- 编辑已有作品时从当前 Work 回填；恢复上传草稿时优先使用自动保存的表单和图片，新建与编辑作品一致。只有不含表单快照的旧草稿仍沿用当前作品资料。
- 编辑权限沿用作品资料权限。游戏详情页的更多信息直接追加到右栏“作品资料”卡片的制作名单字段列表中，统一使用左侧标题、右侧内容的行样式，不设独立标题或区块，不放在左侧简介区。按原文安全转义展示，保留内容换行；无内容时隐藏，不替换用户填写的词语。

数据归属与存储结构见[游戏领域架构的扩展资料](./game-domain-architecture.md#8-扩展资料)。

## 译者条目

- 作者、译者复用 Creator 身份、规范名和别名搜索。人物或翻译团队均可作为条目。
- 作者与译者共用标签式输入框，选择候选或按 Enter 添加多人，点击标签编辑署名和关联人物；不按逗号、顿号或换行自动拆分名称。
- 选择已有条目保存 Creator ID 与本作署名。修改本作署名不改变已关联身份；更换身份需使用选择器的更换操作。
- 默认填写与手动填写使用同一提交逻辑：名称匹配规范名或别名时复用条目，无匹配时建立条目。规范名和别名按规范化后的名称唯一，不允许跨人物重名。
- 打开页面、改变输入和保存浏览器偏好均不建立人物。实际提交时才建立或关联，并随作品署名一起入库。
- 默认名称来自当前用户显示名，不表示 User 与 Creator 绑定，也不授予人物资料管理权。
- 自动预填的自己随新建选择携带 `sourceUserId`，表单和归档草稿保留此来源；手动改名或更换人物时清除。实际提交时，仅来源账号与提交者相同的译者在新建 Creator 时使用提交者头像，并在简介写入可点击的个人主页网址。资料取自服务端当前账号；无头像时保持默认头像，名称已匹配现有人物时不覆盖其资料。
- 同一人物在同一作品可有多个不同职务，同一人物同一职务只保存一次。
- 译者与作者均保留完整的作品署名字段。编辑同一人物时继承原职务标签与备注，新人物默认为空；新版本上传和草稿恢复保留这些字段。
- 译者关联使用 `work_staff.role_key = "translator"`，公开署名链接到人物页，参与作品索引展示译者职务。
- 上传不能覆盖已有 Creator 的公共简介、头像、网站或别名。

## 初始值与浏览器偏好

初始值优先级：恢复的归档资料草稿、已有作品署名、当前账号浏览器偏好、当前用户显示名。编辑已有作品或恢复草稿时，偏好不得覆盖已有值；初始化不反向写入偏好。

新建作品没有偏好时，两项声明均未选择，内部预填当前显示名作为待建立的译者条目。偏好只保存翻译声明与译者选择，不保存原创声明或其他作品字段。

偏好键为 `viprpg.upload.translation-preference.v2:<userId>`，结构为 `{ version: 2, isTranslation: boolean, translators: ConfirmedCreatorSelection[] | null }`，译者只保存 `kind: existing` 的真实人物 ID 与本作署名，不携带作品专属的职务标签或备注。未发布的新人物仅保存在表单和恢复草稿中，不写入人物偏好。空译者偏好回退当前显示名；不支持的结构、解析错误或存储异常均忽略，不阻塞上传。不按显示名自动认定人物身份。

## 提交与恢复

- 游戏文件上传并校验完成后，表单每次变更自动写入当前浏览器的上传草稿，包括标题、简介、日期、语言、署名、角色、标签、更多信息、声明、发布状态、来源网址，以及封面、预览图和新角色脸图。保存不依赖字段完整或点击“确认作品资料”；图片按选择的文件保存，不保存尚未确认的裁剪弹窗状态。
- 自动保存与确认提交分离。恢复草稿一律回到未确认状态，必须再次确认资料才会提交；点击“修改资料”也保留表单快照。自动保存失败时提示不要刷新或关闭页面。
- 归档资料通过 `ArchiveCommitMetadata.workStaff` 携带译者、作者及其他制作人员；不存在单独可编辑的译者文本字段。
- 外链发布和已有作品保存使用 `translators` JSON 选择列表及 `extra_staff` JSON 职务列表，服务端验证身份、职务和翻译声明。
- 原创与翻译声明仍属于 Work 和归档 manifest 的游戏元数据；译者与其他制作人员一样属于 Work 关联，不加入文件快照的独立署名字段。
- 所有作品编辑与草稿恢复路径保留已选择的身份、本作署名和额外职责；移除署名不删除人物条目。
- 归档提交、已完成任务查询、外链发布和作品保存均返回实际落库的译者身份。客户端收到成功结果后更新译者偏好；提交响应丢失后的结果查询和恢复草稿清理也使用同一身份结果。
- 不新增账号认领、跨设备偏好同步、素材署名系统或独立翻译模型。

验收遵循根目录 AGENTS.md，按改动运行静态检查及已有稳定契约，不以人工浏览器流程作为日常功能完成条件。
