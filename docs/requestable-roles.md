# 可申请角色配置

六个角色开放申请，全员授予关闭。申请理由选填，权限申请页只展示角色介绍。管理员申请仅申请人和当前超级管理员可见，由超级管理员批准或驳回；其他申请沿用任一管理员首次有效处理生效的规则。已有个人角色关系保留。

| 角色 | key | 优先级 | 权限范围 |
| --- | --- | ---: | --- |
| 管理员 | `admin` | 700 | 保留 `SYSTEM_ROLE_PERMISSIONS.admin` 的 62 项业务管理权限：作品发布与维护、归档管理、资料管理、评论与讨论管理、默认表情、较低层级用户与角色管理、普通申请审批、仪表盘和一致性检查。角色策略、软件发布、最终存储清理和全站安全审计不在此角色范围内。 |
| 维基人 | `wiki_editor` | 300 | 以下作者、角色、作品三个维护组的并集，共 26 项权限。 |
| 维护作者信息 | `creator_editor` | 150 | 公开作者编辑、查看非公开作者、编辑全部作者资料，共 3 项。包括名称、别名、网站、简介与头像。 |
| 维护角色信息 | `character_editor` | 250 | 管理资料读取、创建角色、名称与别名、素材上传与绑定、默认头像、分类新增与修改及空分类删除、归属新增修改移除、目录排序、来源维护，共 13 项。 |
| 维护作品信息 | `work_editor` | 250 | 公开作品查找、非公开作品读取、全站作品资料编辑、标签读取与维护、普通关联新增修改删除、翻译关联新增删除，共 10 项。 |
| 讨论版版主 | `forum_moderator` | 500 | 讨论内容审核、公开主题策展、全站讨论 TAG 管理，共 3 项。包括举报、隐藏恢复、锁定、置顶、加精与标签整理。 |

三个资料维护组及维基人不包含实体合并、作品上下架、归档文件和维护者管理。作品资料编辑允许修改作品中的作者、角色和标签关系，不授予独立修改作者、角色主资料的权限。维护角色信息删除的是空分类或指定归属，不是角色身份。

讨论版版主不包含作品、作者或角色页的评论审核、账户封禁、角色分配、默认表情管理。版主不获得管理员身份和申请审批资格。

精确权限清单使用 `lib/authz/permissions.ts` 的 key。维基人模板与三个资料维护组保持一致；角色介绍和配置保存在数据库。当前配置同时写入本地数据库、固定开发种子和预生产；已有角色按 key 匹配，保留原 ID 与个人授权。

作者维护复用原 `creator_editor`，由全员开放改为个人审批，并增加后台作者资料维护。原上传者关闭开放申请，既有全员开放状态和个人授权保留。讨论策展人和已停用资料协作组保持原定义与成员，但不开放申请。

初始化 schema 启用管理员及作者维护申请；其余自定义角色来自固定种子。预生产的干净种子导入仍只复制自定义角色及功能配置，不复制用户或授权关系。
