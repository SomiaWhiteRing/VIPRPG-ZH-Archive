## 演练中修复

1. 网站 notesUrl 使用 `/resources#windy-translator`，旧解析器拒绝片段，导致真实检查失败。只为同源说明网页允许片段；接口和下载地址仍拒绝片段，异源链接仍拒绝。
2. WindyTranslator 文件选择文案改为 GitHub 发行 ZIP；切换文件清空上一文件的完成提示。
3. 替换因文件占用失败时，恢复流程跳过已与备份一致的文件，避免再次覆盖尚未改动的占用文件。
4. 更新助手恢复成功后的提示改为已恢复旧版和重试建议；系统错误细节留在日志。
