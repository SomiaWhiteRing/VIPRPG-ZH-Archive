# VIPRPG 素材裁切器

用于 VIPRPG 素材保管 Wiki 的 Chromium 扩展。无需构建或安装依赖。

## 安装

1. 在 Chrome 或 Edge 打开扩展管理页。
2. 开启“开发者模式”。
3. 选择“加载已解压的扩展程序”。
4. 选择本目录 `tools/atwiki-material-cropper`。

复制功能需要扩展的剪贴板写入权限。

## 使用

打开 `https://w.atwiki.jp/viprpg_sozai/pages/` 下的角色素材页：

- 页面右上角浮窗可关闭裁切功能，或选择单击后“复制”还是“下载”。
- 鼠标移到标准行走图的一个动画帧上，会描出 `24×32` 的黄色边框。
- 鼠标移到标准脸图的一个表情上，会描出 `48×48` 的绿色边框。
- 左键单击边框内图块，即可按浮窗选择复制或下载裁切后的 PNG。
- 行走图会把整张图左上角像素代表的背景色转换为透明；脸图保留原像素。

浮窗设置只对当前页面有效，刷新后恢复“启用裁切 + 下载”。下载文件名包含素材原名、类型、行号和列号，例如 `face001_zrA-face-r1-c2.png`。

## 逐角色确认头像

1. 打开 VIPRPG 素材保管 Wiki 的角色索引页 `https://w.atwiki.jp/viprpg_sozai/pages/1.html`。
2. 在右上角浮窗选择“逐角色确认头像”。
3. 首次使用时导入仓库中的 `data/character-dictionary.json`；后续会自动恢复。
4. 工具会先按角色日语原名和日文别名匹配索引；没有候选时，自动检查 atwiki 搜索结果并打开第一个包含标准脸图的页面。也可输入页面标题后按 Enter 搜索，输入 `#页码` 或粘贴 atwiki URL 直接打开页面。
5. 工具会读取页面中所有“顔グラ”分区，并优先显示与当前角色同名的分区。逐个选择素材表和一个头像格子，然后确认。
6. 完成或中途备份时，导出映射 JSON。需要连同裁切后的图片交付时，导出头像包 ZIP。

确认进度保存在扩展的本地存储中。映射会记录角色原名、PNG 文件名、atwiki 页面、原素材图和裁切坐标；头像包包含同一份映射、修订后的角色字典和 `portraits/` 下逐角色裁切的 `48×48` PNG。选择“暂不设置”的角色不会生成头像，且会单独列在导出结果中。

当前角色旁的“编辑别名”可增加、修改或删除日文/中文别名。修改会立即用于素材页及分区匹配，并随进度保存在扩展中；选择“导出角色字典”可得到包含这些修改的新 `character-dictionary.json`。角色原名和主译名仍由字典生成流程维护，不在此工具中修改。

工具不会自动写入站点数据库。确认后的头像可在站点角色维护页上传；这能保留人工授权确认与正式发布之间的边界。

## 识别范围

扩展只处理页面正文中的两种 RPG Maker 2000/2003 标准素材：

| 类型 | 原图尺寸 | 裁切网格 |
| --- | --- | --- |
| 行走图 | `288×256` | `12×8`，每格 `24×32` |
| 脸图 | `192×192` | `4×4`，每格 `48×48` |

其他尺寸、广告和页面装饰图片不会被拦截。扩展只读取 `img.atwiki.jp/viprpg_sozai/attach/` 下的附件；复制模式仅把当前裁切 PNG 写入剪贴板，不会上传图片或保存浏览记录。

素材的公开展示不等于可任意再发布；下载和使用前请确认原页面或作者标注的授权条件。
