# 固定本地种子

这份种子以 2026-09-16 审核过的本地 D1/R2 快照为基础，随领域结构和演示数据更新。它用于本地开发环境，包含虚构账号、会话和业务场景；正式数据的初始化与维护遵循[正式部署手册](../../docs/production-deployment.md)。

## 文件格式

| 文件或目录 | 内容 |
| --- | --- |
| `database.sqlite.gz` | 压缩的完整 SQLite 在线备份，包含已提交的 WAL 数据、schema、迁移账本、索引、主键序列和业务记录 |
| `manifest.json` | 捕获时间、数据库大小与校验和、逐表数量，以及 R2 对象的键、源文件路径、摘要、大小和 HTTP／自定义元数据 |
| `objects/` | 仓库角色素材目录之外的 R2 对象字节；已有素材通过 manifest 中的路径复用 |

复制或提交种子时须同时包含 manifest 引用的全部文件。角色 ID、分类归属、头像格子、素材绑定及其他关系由数据库保存；数量和对象清单以 manifest 为准。

## 恢复与捕获

命令、演示账号、隔离状态目录及备份恢复步骤统一见[本地展示数据](../../docs/local-demo-data.md)。

恢复前停止本地服务器；恢复会校验数据库和对象字节，拒绝覆盖已有业务数据。快照恢复后应用尚未登记的有序迁移。捕获前暂停编辑和上传，保证 D1 与 R2 描述同一份状态；捕获使用 SQLite 在线备份，不修改正在使用的数据库。

## 更新约束

- 结构以仓库迁移链及快照内的 `d1_migrations` 账本核对；已应用迁移文件保持不可变。
- 更新快照时同步 schema、迁移账本、manifest、对象引用及对应的审核或演示数据。
- 角色申请配置见[可申请角色](../../docs/requestable-roles.md)，展示场景见[本地展示数据](../../docs/local-demo-data.md)；具体授权由种子中的角色和权限记录决定。
- 只捕获审核过的本地开发数据，真实正式账号与会话不得进入开发种子。
